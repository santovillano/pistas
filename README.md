# Decorte para Windows

Optimizador de cortes de planchas. By Vincent Calavera.

`Decorte-Setup.exe` se instala con un solo clic (sin permisos de administrador), crea el acceso
directo en el escritorio y en el menú Inicio, y abre la app. Usa Microsoft Edge WebView2, que ya
viene con Windows 10/11 (si falta, el instalador lo agrega).

Se compila automáticamente con GitHub Actions (`.github/workflows/windows.yml`).
